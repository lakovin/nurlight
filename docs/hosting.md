# Хостинг бота

Боевой бот работает на ноутбуке Нурадила. Он опрашивает Telegram сам, поэтому домен и открытые порты
не нужны: достаточно включённого ноутбука и интернета.

## Главное правило: один токен — один запущенный бот

Если запустить боевого бота в двух местах, Telegram отвечает `Conflict: terminated by other getUpdates
request`, а уведомления приходят дважды. Поэтому боевой токен есть только на ноутбуке, где работает бот,
а у остальных свои тестовые боты.

## Боевой бот (ноутбук Нурадила)

1. `Pull origin` на ветке `main`. Если в нём есть миграции, дождаться, пока Нурдаулет применит их к Neon.
2. Двойной щелчок по `start_bot.bat`. В окне должно появиться `Run polling for bot @...`.
3. Окно не закрывать: пока оно открыто, бот работает и сам перезапускается после сбоев.

Чтобы бот не выключался вместе с экраном (Windows 11): Параметры → Система → Питание → сон при питании
от сети «Никогда»; Панель управления → Электропитание → «Действие при закрытии крышки» → от сети
«Действие не требуется». Ноутбук держать на зарядке.

Автозапуск при входе в Windows: `Win+R` → `shell:startup` → положить туда ярлык на `start_bot.bat`.

## Запуск у остальных (для разработки и проверки)

1. @BotFather → `/newbot` → получить токен **своего** тестового бота.
2. `.env.example` скопировать в `.env`: `BOT_TOKEN` своего бота, `DATABASE_URL=sqlite:///db.sqlite3`,
   `PAYMENT_DEMO=1`.
3. Windows: `python -m venv venv`, `venv\Scripts\pip install -r requirements.txt`.
   macOS: `python3 -m venv venv`, `venv/bin/pip install -r requirements.txt`.
4. В папке `admin_panel`: `migrate`, `seed_demo`, `fill_translations` (через `manage.py`).
5. Windows: `start_bot.bat`; macOS: `sh start_bot.sh`.

Боевая база при этом не затрагивается.

## Если ноутбук будет недоступен (например, на защите)

Боевой токен на время можно отдать другому участнику лично. Сначала остановить бота на ноутбуке, потом
запускать у него с боевыми `BOT_TOKEN`, `DATABASE_URL`, `GEMINI_API_KEY`, `PAYMENT_PROVIDER_TOKEN`.
`PAYMENT_DEMO` на боевом боте не нужен.

## Что учесть

- **Часы Neon.** На бесплатном тарифе они ограничены, а база засыпает без запросов. Бот опрашивает её каждые
  10 секунд, только пока есть активные заказы моложе 3 часов; иначе раз в час или когда пишет клиент.
  Поэтому о смене статуса забытого старого заказа клиент может узнать с задержкой до часа.
- **Перезапуск.** Корзины и незавершённые оформления хранятся в памяти и при перезапуске теряются,
  сами заказы — в базе и сохраняются.
