# Nurlight Delivery Bot

Дипломный проект команды Nurlight: Telegram-бот службы доставки, в котором клиенты выбирают блюда,
оформляют заказ, оплачивают его и следят за статусом, и веб-панель на Django, где работают
операторы и кухня. Клиентского сайта-магазина нет: заказы принимаются только в боте. Для бизнесов
есть рекламная визитка (папка `landing/`).

Бот (aiogram 3) и панель (Django) работают с одной базой данных. Таблицы описаны
моделями Django в `admin_panel/delivery/models.py`, а бот использует эти же модели через ORM.

## Структура

```
bot/                  # Telegram-бот (aiogram 3)
├── main.py           # точка входа: роутеры, определение языка, фоновые уведомления

├── middlewares.py    # определение языка клиента для каждого сообщения
├── states.py         # FSM-состояния оформления заказа
├── handlers/         # обработчики: старт и язык, каталог, корзина, заказ, мои заказы, оплата, FAQ, AI
├── keyboards/        # кнопки (тексты берутся из переводов)
├── services/         # работа с базой, доставка, оплата, уведомления, AI, валидация
├── tests/            # автотесты бота
└── tests_i18n.py     # проверка полноты переводов
admin_panel/          # Django-проект
├── manage.py
├── config/           # settings, urls
├── delivery/         # модели, панель (заказы, кухня, статистика), роли, платежи

docs/                 # требования, сценарии, схема базы, инструкции
```

## Запуск (Windows, PowerShell)

Нужен Python 3.11+.

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env   # вписать BOT_TOKEN от @BotFather
```

Для разработки проще всего SQLite: в `.env` укажите `DATABASE_URL=sqlite:///db.sqlite3`
и токен **тестового** бота (один токен нельзя запускать в двух местах). Не работайте с боевой базой
(Neon) без необходимости: бот и сайт у команды используют одну общую базу.

Создать таблицы и заполнить демо-данными:

```powershell
cd admin_panel
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser   # свой администратор, по желанию
```

Панель (http://127.0.0.1:8000/admin/):

```powershell
cd admin_panel
python manage.py runserver
```

Бот (из корня репозитория):

```powershell
python -m bot.main
```

Тесты:

```powershell
python -m unittest discover -s bot/tests -t . -v          # бот: 46 тестов, временная SQLite
cd admin_panel; python manage.py test                     # панель
```

Геолокацию Telegram на компьютере отправить нельзя: заказ в боте проверяйте с телефона.

## Переменные `.env`

| Переменная | Что делает |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `DATABASE_URL` | база: `sqlite:///db.sqlite3` для разработки или строка PostgreSQL (Neon) |
| `GEMINI_API_KEY` | ключ Gemini для виртуального оператора |
| `PAYMENT_PROVIDER_TOKEN` | токен платёжного провайдера с `TEST` (настоящая оплата; пусто — выключена) |
| `PAYMENT_DEMO` | `1` — демо-оплата без списания денег (кнопка «Оплатить (тест)»), если нет токена |
| `DELIVERY_FEE`, `DELIVERY_FREE_FROM` | доставка: 500 ₸, бесплатно от 5 000 ₸ |
| `DJANGO_*`, `SHOP_ENABLED` | настройки панели (см. `.env.example` и [docs/deploy.md](docs/deploy.md)) |

## Статусы заказа

Новый → Принят → Готовится → Упаковывается → Готов → Передан курьеру → В пути → Доставлен;
отдельно «Отменён». Кухня ведёт заказ от «Принят» до «Готов», курьер назначается только на готовый заказ.

## Доставка и оплата

- Доставка входит в сумму заказа: 500 ₸, а при заказе блюд от 5 000 ₸ бесплатно.
- Оплата одним счётом на весь заказ (блюда + доставка) во встроенных платежах Telegram.
  Пока настоящий провайдер не подключён, работает демо-режим (`PAYMENT_DEMO=1`).
- Минимальный платёж в Telegram — 518 ₸. Оплаченный заказ клиент не отменяет, возврат оформляет оператор.

## Роли в панели

Группы создаются автоматически при `migrate`. Чтобы выдать роль, в разделе «Пользователи»
отметьте «Статус персонала» и добавьте пользователя в группу.

| Роль | Что может |
|---|---|
| Оператор | заказы: просмотр, создание, смена статуса, назначение курьера; клиенты; справочники — только просмотр |
| Кухня | раздел «Кухня»: заказы от «Принят» до «Готов», кнопки «Начать готовить → Упаковать → Готово» |
| Руководитель | всё в разделе «Доставка», включая удаление и страницу статистики |

## Что уже есть

**Бот**
- выбор языка (русский, казахский, английский) при `/start`, смена по `/language`;
- каталог по категориям, недоступные товары показываются с пометкой «нет в наличии»;
- корзина, оформление заказа: геолокация (адрес только геолокацией) → уточнение адреса (по желанию)
  → телефон → комментарий → проверка → подтверждение, с возможностью изменить любое поле;
- «Мои заказы»: список, карточка с составом, обновление статуса, отмена пока заказ «Новый» и не оплачен;
- оплата заказа (настоящая по токену или демо);
- уведомления клиенту о смене статуса заказа на его языке (бот сам следит за базой);
- FAQ из базы, виртуальный оператор на Gemini (отвечает про меню, цены, доставку и статус заказов клиента);
- команды и кнопки меню прерывают оформление заказа, корзина сохраняется.

**Панель**
- заказы: фильтры, поиск, смена статуса и курьера, массовые действия, ссылка «Открыть на карте»;
- раздел «Кухня», роли, статистика для руководителя;
- панель на русском, казахском и английском.

Подробнее про бота и правила работы с ним: [docs/bot-guide.md](docs/bot-guide.md).
