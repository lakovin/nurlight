# Nurlight Delivery Bot

Дипломный проект команды Nurlight: Telegram-бот, через который клиенты службы доставки
оформляют и отслеживают заказы, и веб-панель на Django, где операторы их обрабатывают.

Бот (aiogram 3) и панель (Django) работают с одной базой данных. Таблицы описаны
моделями Django в `admin_panel/delivery/models.py`, а бот использует эти же модели через ORM.

## Запуск

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN от @BotFather
```

Для разработки проще всего SQLite — в `.env` укажите `DATABASE_URL=sqlite:///db.sqlite3`.
Для PostgreSQL — строку вида `postgres://user:password@localhost:5432/nurlight`.

Создать таблицы и заполнить демо-данными (каталог, курьеры, ~60 заказов за 2 недели,
пользователи `manager` и `operator` с паролем `nurlight-demo`):

```bash
cd admin_panel
python manage.py migrate
python manage.py seed_demo
python manage.py createsuperuser   # свой администратор, по желанию
```

Тесты панели: `cd admin_panel && python manage.py test delivery`.

Панель (http://127.0.0.1:8000/admin/):

```bash
cd admin_panel
python manage.py runserver
```

Бот (из корня репозитория):

```bash
python -m bot.main
```

## Статусы заказа

новый → принят → передан курьеру → в пути → доставлен; отдельно «отменён».

## Роли в панели

Группы создаются автоматически при `migrate`. Чтобы выдать роль, в разделе «Пользователи»
отметьте «Статус персонала» и добавьте пользователя в группу.

| Роль | Что может |
|---|---|
| Оператор | заказы: просмотр, создание, смена статуса, назначение курьера; клиенты; справочники — только просмотр |
| Руководитель | всё в разделе «Доставка», включая удаление и страницу статистики |

## Что уже есть

- модели: Client, Category, Product, Order, OrderItem, Courier, FAQ;
- панель заказов: фильтры по статусу, курьеру и дате, поиск, смена статуса и курьера прямо в списке,
  массовые действия «Принять» и «Отменить»; при назначении курьера заказ сам переходит
  в «Передан курьеру», сумма пересчитывается по позициям;
- статистика для руководителя (кнопка «Статистика» над списком заказов): заказы, выручка,
  средний чек, доля отмен, график по дням, статусы, популярные товары, курьеры;
- бот: `/start` (регистрирует клиента) и каталог по категориям.
